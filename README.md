# 🤖 Telegram Bot для сканирования QR-кодов чеков

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://python.org)
[![Telegram Bot API](https://img.shields.io/badge/Telegram-Bot%20API-blue.svg)](https://core.telegram.org/bots/api)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Telegram бот для автоматического сканирования QR-кодов чеков с извлечением и сохранением данных в базу данных.

## ✨ Возможности

- 📱 **Сканирование QR-кодов** - Отправьте фото с QR-кодом чека
- 🔍 **Извлечение данных** - Автоматическое извлечение информации из QR-кода
- 💾 **Сохранение в БД** - Все данные сохраняются в SQLite базу данных
- 🚫 **Проверка дубликатов** - Предотвращение повторного добавления одного чека
- 📊 **Статистика** - Просмотр статистики по отсканированным чекам
- 🛡️ **Безопасность** - Проверка корректности данных и валидация

## 📋 Извлекаемые данные

- 📅 **Дата чека** - Дата совершения покупки
- 🕐 **Время чека** - Время совершения покупки  
- 💰 **Сумма чека** - Общая сумма покупки в рублях
- 🏢 **ФН** - Фискальный накопитель
- 📄 **ФД** - Фискальный документ
- 🔢 **ФП** - Фискальный признак
- 🏪 **ИНН продавца** - Идентификационный номер налогоплательщика
- 👤 **ID пользователя** - ID пользователя Telegram
- 📅 **Дата сканирования** - Когда был отсканирован чек

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone <repository-url>

```

### 2. Настройка окружения


```bash

# Редактирование конфигурации
```

```env

```

### 4. Запуск

```bash

./run.sh

# Или ручной запуск
python main.py
```

## 🛠️ Технические детали

### Поддерживаемые форматы QR-кодов

- Стандартный фискальный формат: `t=YYYYMMDDThhmm&s=сумма&fn=ФН&i=ФД&fp=ФП&n=тип`
- С дополнительными параметрами (ИНН, название организации)
- Автоматическое определение формата

### База данных

- **SQLite** - Легкая встроенная база данных
- **Таблица receipts** - Хранение всех данных чеков
- **Индексы** - Оптимизация запросов по user_id, qr_hash, scan_date
- **Проверка дубликатов** - По хешу уникальных полей (ФН+ФД+ФП)

### Обработка изображений

- **pyzbar** - Декодирование QR-кодов
- **Pillow** - Обработка изображений
- **Автоматическая очистка** - Удаление временных файлов

## 🐛 Устранение неполадок

### Частые проблемы

1. **"QR-код не найден"**
   - Проверьте качество фото
   - Убедитесь, что QR-код четко виден
   - Попробуйте другое освещение

2. **"Не удалось извлечь данные"**
   - Убедитесь, что это QR-код чека
   - Проверьте, что QR-код не поврежден

3. **"Ошибка установки зависимостей"**
   - Установите системные зависимости (libzbar)
   - Обновите pip: `pip install --upgrade pip`

4. **"Бот не отвечает"**
   - Проверьте токен бота
   - Проверьте интернет-соединение
   - Посмотрите логи: `tail -f logs/bot.log`

### Диагностика
